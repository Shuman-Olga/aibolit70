# Айболит — Next.js + TypeScript

Новая версия проекта на Next.js App Router, React и TypeScript. Ветка создана от `refactor`; исходный проект сохранён.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Стек

- Next.js App Router
- React + TypeScript
- Адаптивная главная страница в стиле сайта [aibolit70.ru](https://aibolit70.ru/)

Логотип в шапке пока воспроизведён типографически; оригинальный файл логотипа следует перенести из исходных ассетов сайта в `public/` и подключить в `src/app/page.tsx`.
